# Citadel — локальный агент для Windows

Цитадель получает задачу обычным текстом или голосом, сама выбирает инструменты, выполняет последовательность действий и проверяет результаты. Решения принимает локальная модель через Ollama. Проект рассчитан на разные компьютеры: установщик готовит Python, браузер, зависимости и модель.

Платный API и ключи не требуются. Модель и голос работают локально; поиск и открытие сайтов используют интернет. Голосовой слой использует `faster-whisper` и Silero TTS.

Репозиторий: <https://github.com/chilopek/local-assistant>

## Возможности

- локальная обработка запросов через Ollama;
- выбор модели по режиму производительности;
- вызов инструментов из естественного языка;
- цикл до 24 шагов с обработкой ошибок, проверкой результата и журналом;
- общий поиск в интернете и чтение HTML, JSON, XML и текстовых API;
- отдельный управляемый браузер: страницы, вкладки, ссылки, поля ввода и кнопки;
- чтение окон Windows через UI Automation и взаимодействие с их элементами;
- выполнение Python для вычислений, документов и другой автоматизации;
- чтение и запись файлов, включая абсолютные пути с подтверждением;
- запуск PowerShell-команд с подтверждением;
- запуск приложений с подтверждением;
- простая локальная память на SQLite;
- автоматическая установка Python, Ollama и модели; Git используется опционально;
- создание ярлыка на рабочем столе;
- сборка переносимого EXE-установщика через GitHub Actions;
- push-to-talk режим: нажал Enter, сказал команду, нажал Enter;
- офлайн распознавание русской речи;
- локальное озвучивание ответов без Windows SAPI.
- интерфейс с диалогом, панелью активности, подтверждениями и кнопкой остановки;
- глобальная клавиша `Ctrl+Alt+C`;
- режим ожидания ключевого слова `цитадель`.

## Установка на Windows

### Вариант 1: EXE-установщик

Скачайте [актуальный `LocalAssistantSetup.exe` из релиза v0.2.0](https://github.com/chilopek/local-assistant/releases/download/v0.2.0/LocalAssistantSetup.exe), запустите файл и выберите режим:

- `auto` — автоматический подбор по характеристикам компьютера;
- `fast` — минимальная задержка и небольшая модель;
- `balanced` — рекомендуемый баланс скорости и качества;
- `power` — более сильная модель для производительного компьютера.

После выбора режима установщик предложит включить голосовой слой. Он добавит зависимости распознавания и озвучивания, а модели речи скачаются при первом запуске голосового режима. Установщик скачивает актуальные файлы из этого репозитория и размещает приложение в каталоге пользователя. Git используется при наличии, но не является обязательным: без него проект скачивается ZIP-архивом. Администраторские права обычно не требуются; зависимости устанавливаются через `winget` или официальные загрузчики. Если голосовые пакеты не удалось скачать, базовая текстовая версия всё равно завершит установку.

Установщик использует установленный 64-битный Python 3.12+ только после проверки создания окна Tcl/Tk. Пути Tcl/Tk определяются по самому интерпретатору, включая запуск из виртуального окружения. Если подходящий Python не найден, установщик готовит Python 3.12 с компонентом Tcl/Tk. Повреждённое `.venv` переносится в `.venv-backup-*` внутри папки приложения и создаётся заново; пользовательские данные и модели не удаляются.

Для браузерных задач используется установленный Edge или Chrome. Если они недоступны, установщик загружает Chromium. Агент использует собственный профиль `data/browser-profile`; вход на сайты пользователь выполняет сам. Ярлык запускает GUI через `pythonw.exe`, служебные команды выполняются со скрытой консолью.

### Вариант 2: установка из PowerShell

```powershell
git clone https://github.com/chilopek/local-assistant.git
cd .\local-assistant
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1 -RepoUrl "https://github.com/chilopek/local-assistant.git"
```

Для выбора режима вручную:

```powershell
.\install.ps1 -RepoUrl "https://github.com/chilopek/local-assistant.git" -Mode fast
.\install.ps1 -RepoUrl "https://github.com/chilopek/local-assistant.git" -Mode balanced
.\install.ps1 -RepoUrl "https://github.com/chilopek/local-assistant.git" -Mode power
```

Для автоматической установки без меню:

```powershell
.\install.ps1 -RepoUrl "https://github.com/chilopek/local-assistant.git" -Mode auto -NonInteractive
```

Голос можно явно включить или выключить параметром `-Voice on` / `-Voice off`.

Для обновления уже установленной копии используется параметр `-Update`.

## Требования

- Windows 10 или Windows 11;
- интернет для установки, поиска и веб-задач;
- Python 3.12 или новее — установщик ставит его через `winget` или официальный fallback с python.org;
- Ollama — установщик может поставить её автоматически;
- свободное место под выбранную модель и зависимости;
- микрофон и устройство вывода звука для голосового режима.

Примерная рекомендация по режимам:

| Режим | Ориентир | Приоритет |
|---|---|---|
| `fast` | малый объём RAM или слабый CPU/GPU | скорость и экономия памяти |
| `balanced` | большинство современных компьютеров | баланс скорости и качества |
| `power` | производительный компьютер и больше RAM | качество рассуждений |
| `auto` | любой компьютер | автоматический выбор |

Точные требования зависят от выбранной модели, оперативной памяти, видеопамяти и скорости диска. Установщик показывает обнаруженные характеристики перед выбором.

## Запуск из исходников

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup.ps1
.\scripts\run.ps1
```

Если голосовые зависимости не нужны:

```powershell
.\scripts\setup.ps1 -NoVoice
```

По умолчанию `scripts\run.ps1` открывает графический интерфейс. Для запуска старого терминального режима:

```powershell
.\scripts\run.ps1 -Console
```

Или напрямую из активированного виртуального окружения:

```powershell
py -3.12 -m assistant
```

Локальные настройки можно задать в `assistant.local.json`. Этот файл не добавляется в Git и позволяет выбрать модель, рабочую папку и параметры Ollama для конкретного компьютера.

## Примеры команд

Помощник понимает обычные фразы, например:

- «Покажи файлы в рабочей папке»;
- «Прочитай README.md»;
- «Создай файл notes.txt с этим текстом»;
- «Запусти калькулятор»;
- «Выполни проверку версии Python»;
- «Найди актуальную информацию, прочитай источники и сохрани краткую сводку»;
- «Вычисли сумму из этого CSV и запиши результат в отдельный файл»;
- «Открой сайт, найди нужную страницу и прочитай её».

Это примеры, а не список заранее прошитых команд. Агент комбинирует общие инструменты под новую задачу. Качество зависит от выбранной модели; выполнение любого мыслимого запроса не гарантируется. Текстовая модель читает доступные элементы интерфейса, но не распознаёт пиксели скриншота.

Запуск кода и программ, изменения в интерфейсах и доступ за пределами рабочей папки требуют подтверждения. Отклонение действия останавливает задачу. Кнопка «Остановить» запрещает следующие шаги после завершения текущей операции; уже сделанные изменения автоматически не откатываются.

В голосовом режиме запуск выполняется так:

```powershell
.\scripts\run.ps1
```

Если в локальной конфигурации голос выключен, можно запустить его принудительно:

```powershell
.\.venv\Scripts\python.exe -m assistant --voice
```

Во время работы доступны `/voice` и `/text` для переключения режимов. Для выхода используйте `/exit` или скажите «выход».

В GUI доступны три режима микрофона:

- **Ключевое слово «цитадель»** — помощник ждёт слово и обрабатывает только фразы после него;
- **Всегда слушать** — каждая распознанная фраза отправляется помощнику;
- **Push-to-talk** — запись идёт только пока включён микрофон.

Во всех режимах микрофон запускается кнопкой или глобальной комбинацией `Ctrl+Alt+C`.

## Безопасность

Модель не получает прямой доступ к Windows. Она только предлагает вызов одного из разрешённых инструментов, а приложение отдельно проверяет имя инструмента, аргументы и необходимость подтверждения.

Чтение внутри рабочей папки и создание новых файлов в ней разрешены без дополнительных диалогов. Перезапись файлов, доступ к другим папкам, код, программы и изменения в браузере/Windows подтверждаются отдельно. Python и PowerShell не являются песочницей: проверяйте код в окне подтверждения. Содержимое сайтов и файлов передаётся модели как недоверенные данные. Запись с микрофона удаляется после распознавания.

Журнал действий хранится локально в `data/agent-events.jsonl`, ошибки запуска — в `assistant-launch.log`. Журнал может содержать команды и тексты прочитанных данных; не публикуйте его без проверки.

## Сборка EXE-установщика

Для локальной сборки:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build-installer.ps1
```

Готовый файл появится в `dist\LocalAssistantSetup.exe`. GitHub Actions автоматически собирает этот файл после каждого изменения в ветке `main` и сохраняет его как артефакт workflow.

## Архитектура

```text
пользователь
    ↓
локальное приложение
    ↓
Ollama + выбранная модель Qwen3
    ↓
tool call
    ↓
проверка разрешений и подтверждения
    ↓
действие в Windows
    ↓
результат обратно модели → проверка → следующий инструмент или ответ
```

## Проверки

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
powershell -NoProfile -ExecutionPolicy Bypass -File tests\test-installer.ps1
.\.venv\Scripts\python.exe tests\browser_smoke.py
```

При запущенной Ollama можно отдельно проверить реальный выбор инструментов моделью: `tests\live_agent_smoke.py file` и `tests\live_agent_smoke.py web`. Автотесты Windows запускаются на Python 3.12, 3.13 и 3.14.
