# Локальный голосовой помощник

Первый этап проекта: текстовое локальное ядро, которое умеет принимать команды, выбирать инструменты и выполнять безопасные действия на компьютере.

## Требования

- Windows 10/11
- Python 3.12+
- Ollama с доступным локальным API на `http://127.0.0.1:11434`
- Для этого компьютера рекомендуется `qwen3:4b-instruct`

## Запуск

```powershell
cd .\local-assistant
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup.ps1
.\scripts\run.ps1
```

Или напрямую:

```powershell
py -3.12 -m assistant
```

## Установка на другой компьютер

После публикации проекта в GitHub установщик можно запустить так:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1 -RepoUrl "https://github.com/USERNAME/local-assistant.git"
```

Установщик покажет RAM и GPU, предложит выбрать режим, установит Git/Python/Ollama, создаст виртуальное окружение, загрузит модель и создаст ярлык на рабочем столе.

Режимы: `fast` — минимальная задержка, `balanced` — рекомендуемый вариант, `power` — более сильная модель, `auto` — выбор по характеристикам компьютера.

Для более слабого компьютера можно выбрать быструю модель:

```powershell
.\install.ps1 -RepoUrl "https://github.com/USERNAME/local-assistant.git" -Mode fast
```

Для обновления уже установленной копии используется `-Update`. Для установки без меню добавьте `-NonInteractive -Mode auto`.

## EXE-установщик

Для сборки одного Windows-файла установки:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\build-installer.ps1
```

Готовый файл появится в `dist\LocalAssistantSetup.exe`. Он открывает графическое окно, предлагает режим модели и запускает установку из GitHub.

Помощник работает в терминале. Команды, которые могут изменить файлы, запустить программу или выполнить PowerShell, требуют подтверждения.

## Архитектура

```text
пользователь → Ollama/Qwen3 → tool call → проверка разрешений → действие → результат
```

Модель не получает прямой доступ к системе. Она только предлагает вызов инструмента, а приложение отдельно проверяет имя инструмента, аргументы и необходимость подтверждения.
